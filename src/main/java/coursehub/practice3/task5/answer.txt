1) Identifiable - interface Подразумевает наличие id и getId() у объекта.
Не абстрактный класс из-за одинарного наследования
Цена изменения низкая - сильно изолирован от остального кода

2) CoursePolicy - interface. Подразумевает наличие методов для проверки возможности выполнять различные действия
цена изменения средняя - придется менять все реализации, но ничего за пределами этих методов.

3) BaseEntity - abstract class так как требует множество полей и методов.
цена изменения высокая, так как почти все данные в программе наследуются от BaseEntity.

4) Formatter - interface. Подразумевает только методы для форматирования.
Цена изменения низкая - сильно изолирован от остального кода

5) ClockProvider - interface. Подразумевает только методы для просмотра времени. 
Цена изменения низкая - сильно изолирован от остального кода
